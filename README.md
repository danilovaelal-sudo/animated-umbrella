Современный, яркий одностраничный лендинг для продажи курса **«КНИГО-ТЕРАПИЯ»**.

## 📋 Структура проекта

```
my.first.lending/
├── index.html       # Основная разметка (все 12 блоков)
├── styles.css       # Стили (артхаус-дизайн, адаптивность)
├── script.js        # Интерактивность (прокрутка, анимации)
└── README.md        # Этот файл
```

## 🎨 Дизайн и визуальный стиль

### Цветовая палитра
- **Фон**: Чистый белый (`#FFFFFF`)
- **Текст основной**: Глубокий черный (`#000000`)
- **Текст вспомогательный**: Серый (`#666666`)
- **Акценты**: Спокойный кирпичный (`#B22222`)

### Шрифты
- **Заголовки**: `Playfair Display` (Google Fonts) - крупный, выразительный
- **Основной текст**: `Inter` (Google Fonts) - современный, читаемый

### Стилистические особенности
- ✨ Артхаусный дизайн с современной типографией
- 🎯 Контрастные цветовые блоки
- 📦 Асимметричные элементы
- 🌊 Много воздуха между блоками
- 🎬 Плавные hover-эффекты на всех интерактивных элементах
- 📱 Полная адаптивность для мобильных устройств

## 📄 Блоки лендинга

1. **Герой** - Яркий первый экран с основным предложением
2. **Боль** - Карточки с болями целевой аудитории
3. **Решение** - Что ты получишь на курсе
4. **Форматы** - Какие книги можно писать
5. **Программа** - 4 этапа обучения по 30 дней
6. **Формат участия** - 10 ключевых преимуществ
7. **Для кого** - Кому подойдет курс
8. **Кому не подойдет** - Честный отсев
9. **Об авторе** - Информация об Елене Даниловой
10. **Тарифы** - 3 варианта участия (Самостоятельно, Группа, Индивидуально)
11. **Результат** - 7 результатов за 30 дней
12. **Финальный** - Зов к действию

## 🔧 Конфигурация и TODO

Все переменные для настройки находятся в `script.js` в объекте `CONFIG`:

```javascript
const CONFIG = {
    startDate: '15 июня',           // TODO: Обновить дату
    paymentUrl: '#',                // TODO: Добавить ссылку на оплату
    tariffs: {
        solo: { price: 5000, url: '#' },
        group: { price: 12000, url: '#' },
        individual: { price: 25000, url: '#' }
    },
    author: { ... }
};
```

### Места для замены:

1. **Дата старта потока**: `script.js` - переменная `startDate`
2. **Цены тарифов**: `script.js` - объект `tariffs`
3. **Ссылки на оплату**: `script.js` - переменная `paymentUrl`
4. **Фото автора**: `styles.css` - класс `.author-placeholder` (заменить на `background-image: url()`)
5. **Реальные ссылки на кнопки**: Кнопки сейчас ведут на `#` (заглушка)

## 🚀 Как использовать

### Быстрый старт

1. Откройте `index.html` в браузере
2. Лендинг готов к просмотру на любом устройстве

### Интеграция с платежной системой

Все кнопки "Записаться" ведут на диалог в VK: `https://vk.me/danilovaelal`

```javascript
// В CONFIG уже установлена ссылка на VK
paymentUrl: 'https://vk.me/danilovaelal'
```

### Добавление аналитики

В `script.js` уже подготовлены функции для отслеживания:

```javascript
trackButtonClick('Записаться');
trackSectionView('pricing');
```

Подключите Google Analytics или Яндекс.Метрику в `<head>` тега `index.html`.

## 📱 Адаптивность

Лендинг адаптирован под:
- 💻 Десктоп (1200px+)
- 📱 Планшет (768px - 1199px)
- 📲 Мобильный (до 480px)

Используются `@media` queries и `clamp()` для плавного масштабирования.

## ✨ Особенности JavaScript

- **Анимация печатного текста** - заголовок "КНИГО-ТЕРАПИЯ" печатается посимвольно
